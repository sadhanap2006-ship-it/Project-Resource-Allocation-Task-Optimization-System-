How to use this page in your viva

        
    
            
  1. Pick an endpoint on the left. The green, blue, amber and red tags are the HTTP methods
                GET, POST, PUT and DELETE.
    2. 
            
  2. Any {id} in the URL becomes a small box you can type into.
    3. 
            
  3. For POST and PUT a sample JSON body is filled in for you. Edit it freely, or press
                Reset to the sample to put it back.
    4. 
            
  4. Press Send. The reply shows the HTTP status code, how long the call
                took, and the response body.
    5. 
            
  5. The requests whose names start with INVALID or MISSING
                are meant to fail. They demonstrate the validation rules and the 400 and 404 handling.
    6. 
        

        

            This page calls exactly the same REST API that every other screen uses, and the same one the
            Postman collection in postman/ tests. Nothing here is a mock.
